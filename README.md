## Younesse HAMADI

🎓 Étudiant en **BUT Réseaux & Télécommunications**, parcours *Développement Système et Cloud*<br>
🔎 À la recherche d'un **stage de 8 à 10 semaines à partir d'avril 2027** en réseaux / systèmes, cloud ou automatisation

Ce qui m'intéresse : les protocoles réseau, la programmation système en C sous Linux et l'automatisation de workflows (n8n, API REST, IA).

### 🛠️ Projets mis en avant

| Projet | Description | Points techniques |
|---|---|---|
| [**tftp-c**](https://github.com/Hamadiy/tftp-c) | Client et serveur TFTP (RFC 1350) | sockets UDP, retransmission, serveur concurrent (`fork`) |
| [**port-scanner-c**](https://github.com/Hamadiy/port-scanner-c) | Scanner de ports TCP concurrent | `connect()` non bloquant, `poll()`, états open / closed / filtered |
| [**subnet-calculator-c**](https://github.com/Hamadiy/subnet-calculator-c) | Calculateur de sous-réseaux IPv4 et planificateur VLSM | masques, wildcard, VLSM, tests unitaires |
| [**tcp-chat-c**](https://github.com/Hamadiy/tcp-chat-c) | Serveur de chat TCP multi-clients | multiplexage `poll()`, protocole texte, tests d'intégration |

Chaque projet est compilé et testé automatiquement avec **GitHub Actions** (gcc et clang, `-Werror`).

### 🤖 Automatisation

**Projet de fin d'études – automatisation d'une plateforme Moodle avec n8n.** À partir du nom d'un cours, le workflow génère les vidéos pédagogiques, le support de cours et les TD en PDF. Il publie ensuite automatiquement les vidéos sur YouTube et les documents sur Google Classroom.
